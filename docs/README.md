# DecayCore — formerly CamillaFIR

**CamillaFIR has been renamed to DecayCore.**

DecayCore generates high-precision FIR filters for CamillaDSP and other FIR-capable DSP engines. It focuses on physically sane, band-limited room correction, controlled low-frequency decay, phase-aware correction, and automated target optimization.

## Project moved

The project is now maintained under the new name:

➡️ [DecayCore](https://vilhovalittu.github.io/DecayCore/)

This repository is kept for historical reference and redirect purposes only.  
No further updates will be released under the CamillaFIR name.
